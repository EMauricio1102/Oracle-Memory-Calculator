# Oracle-Memory-Calculator
Oracle Memory Calculator is a lightweight utility that helps DBAs and system administrators size Oracle SGA and PGA memory settings, generate Oracle-ready configuration values and SQL commands, and streamline capacity planning through real-time calculations, validation, and visual change tracking.

## Features

- Oracle SGA/PGA sizing
- Oracle SQL parameter generation
- Real-time calculations
- Percentage ↔ GiB synchronization
- Visual change highlighting
- Reset functionality
- Windows executable support
